# 《清静经》参考模块

> 太上老君说常清静经（东汉·葛玄笔录），全文仅392字，信息密度极高。
> 与觉察助手的关联：清静经提供了"观空→遣欲→真静→常应常静"的完整路径，是东方哲学模块的核心组件。

## 全文

老君曰：大道无形，生育天地；大道无情，运行日月；大道无名，长养万物；吾不知其名，强名曰道。夫道者：有清有浊，有动有静；天清地浊，天动地静。男清女浊，男动女静。降本流末，而生万物。清者浊之源，动者静之基。人能常清静，天地悉皆归。

夫人神好清，而心扰之；人心好静，而欲牵之。常能遣其欲，而心自静，澄其心而神自清。自然六欲不生，三毒消灭。所以不能者，为心未澄，欲未遣也。能遣之者，内观其心，心无其心；外观其形，形无其形；远观其物，物无其物。三者既悟，唯见於空；观空亦空，空无所空；所空既无，无无亦无；无无既无，湛然常寂；寂无所寂，欲岂能生？欲既不生，即是真静。真常应物，真常得性；常应常静，常清静矣。如此清静，渐入真道；既入真道，名为得道，虽名得道，实无所得；为化众生，名为得道；能悟之者，可传圣道。

老君曰：上士无争，下士好争；上德不德，下德执德。执著之者，不名道德。众生所以不得真道者，为有妄心。既有妄心，即惊其神；既惊其神，即著万物；既著万物，即生贪求；即生贪求，即是烦恼。烦恼妄想，忧苦身心。但遭浊辱。流浪生死，常沉苦海，永失真道。真常之道，悟者自得，得悟道者，常清静矣。

## 觉察助手应用点

### 1. 苦恼因果链（晚间 R2 改写引导）

```
妄心 → 惊神 → 著万物 → 贪求 → 烦恼
```

**对应场景**：
- 刷手机：看到标题（妄心）→ 注意力被抢（惊神）→ 沉浸内容（著万物）→ 想看更多（贪求）→ 时间没了正事没干（烦恼）
- 交易FOMO：听到消息 → 紧张 → 盯盘 → 想追 → 亏损后悔
- 写作拖延：想到要写 → 焦虑 → 刷"准备材料" → 觉得还不够 → 更焦虑

**引导方式**：帮用户定位自己在因果链的哪一环，阻断任意一环即可。不是五环全断。

### 2. 真常应物（产品定位核心）

> 「真常应物，真常得性；常应常静，常清静矣。」

**含义**：真正的清静不是躲开世界，是在世界中保持清明。

**产品映射**：觉察助手不教用户逃避手机/信息，而是帮用户在信息洪流中保持清明。不是冥想APP，是"应物不迷"的训练。

### 3. 三层观空（晚间 R2 注意力回归）

```
内观其心，心无其心 → 我的念头不是我
外观其形，形无其形 → 我的身体反应不是我
远观其物，物无其物 → 外部世界也不定义我
```

**引导方式**：当用户说"我又被手机带走了"，不是评判，而是引导看见"被带走的那个念头本身也不是我"。

### 4. 澄心遣欲（晨间意图设定）

> 「常能遣其欲，而心自静，澄其心而神自清。」

**关键区分**：遣欲 ≠ 压欲。不是"不能有欲望"，是"看见欲望，不被它带走"。与觉察助手的核心机制一致：看见 → 选择 → 回来。

## 与其他模块的关系

| 关系 | 说明 |
|------|------|
| 庄子（为什么要放下）→ **清静经（怎么放下）** → 王阳明（放下后怎么行动） | 东方哲学递进三角 |
| 清静经「遣欲」≈ 微习惯「不靠意志力」 | 不对抗，顺流 |
| 清静经「观空」≈ CBT「认知解离」 | 看见念头≠被念头控制 |
| 清静经「真常应物」≈ 心流「全情投入」 | 在活动中保持清明 |
| 清静经「妄心→烦恼」≈ 三重脑「理智脑打不过」 | 欲望的底层机制 |

## Agent 调度规则

- 用户说"我停不下来刷手机" → 用**因果链**定位在哪一环，阻断
- 用户说"我知道不该焦虑但控制不住" → 用**澄心遣欲**（不是控制，是看见）
- 用户说"我想逃离这一切" → 用**真常应物**纠正（不是逃离，是在纷扰中回来）
- **不要对首次/回归用户抛"观空""遣欲"等术语**，用口语化表达：
  - 观空 → "看看这个念头，它是不是真的那么重要？"
  - 遣欲 → "看见自己想刷手机，然后自己选择放下"
  - 真常应物 → "不逃离，回来"
