# TA 沟通分析：三种自我状态与人生坐标

融入觉察助手的参考框架。来源：Robert de Board《蛤蟆先生去看心理医生》（Counselling for Toads），核心理论来自 Eric Berne 的沟通分析（Transactional Analysis）。

## 三种自我状态

每个人的人格由三种状态构成，在不同时刻切换。

### 儿童自我状态
由童年遗迹搭建。行为像自己小时候，与真实年龄无关。
- **自然型儿童**：基本情感——快乐、悲伤、恐惧、愤怒
- **适应型儿童**：为应对父母发展出的防御——顺从、取悦、依赖、不敢表达愤怒

**释放愤怒的层级**（由弱到强）：退缩 → 厌烦 → 拖延 → 郁闷 → 任性 → 怄气 → 撒泼 → 叛逆

### 父母自我状态
从父母那里学到的价值观、道德观和评判标准。
- **挑剔型父母**：批评、审判、控制（"你怎么又搞砸了"）
- **养育型父母**：安慰、鼓励、支持（"没关系，再试一次"）

### 成人自我状态
用理性应对当下现实。不被童年情绪围困，不被父母声音驱使。需要刻意的努力和思考才能进入。

**核心原则**：只有成人状态才能学到新东西。儿童和父母状态都是在重演过去。

## 人生坐标（Life Positions）

童年形成的底层信念系统，决定了你如何看待自己和他人。

| 坐标 | 典型情绪 | 常见模式 | 极端行为 |
|------|---------|---------|---------|
| **我好，你也好** | 平和、连接 | 接纳自己与他人 | 健康 |
| **我好，你不好** | 愤怒、优越 | 指责、控制、投射愤怒 | 谋杀 |
| **我不好，你好** | 悲伤、无力 | 受害者游戏、自怨自艾 | 自杀 |
| **我不好，你也不好** | 绝望、虚无 | 放弃一切连接 | — |

"我好，你也好"不是终点，是需要用一生确认的主动选择。

## 与觉察助手的关系

### 核心映射

| TA 概念 | 觉察助手机制 |
|---------|------------|
| 儿童自我状态 | 四种常见状态（停不下来/启动不了/硬撑着/一直在找） |
| 挑剔型父母自我状态 | "谁在XX？"技术识别内化的自我批判声音 |
| 成人自我状态 | 觉察后体验的新反应 |
| 适应型儿童 | "被允许做不到"的安全环境 |
| 情绪温度计 | 晚间R1"今天感觉如何" |
| 人生坐标 | PERMA评分的底层信念系统 |

### 晚间R1可加引导（可选）

> 今天你有哪个时刻是像个孩子一样反应的？哪个时刻是像父母一样在审判自己？
> （帮用户区分儿童/父母/成人自我状态，不说术语）

### 晚间R2可加追问（可选）

> 那个骂你的声音，是你自己的声音，还是你从某个重要的人那里学来的？
> （帮用户看见"内化的父母声音"）

## 关键原则

- **不讲术语**：不说"儿童自我状态""适应型儿童"，用"像个孩子一样反应""你内化了谁的声音"
- **不挖童年**：觉察助手不是心理治疗，不主动追问童年经历，只在用户自己提到时自然连接
- **只帮看见**：帮用户区分"这是过去的反应"还是"这是你现在的选择"
