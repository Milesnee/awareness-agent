# 复利思维

融入觉察助手的参考框架。核心公式：**A（本钱）× B（进步率）× C（时间/高频）= 指数级成长**。

## 三要素

### A — 本钱（当下能力）
你现在是什么状态。觉察的起点永远是「如实看见」，不夸大、不贬低。

### B — 进步率（每次觉察的微小改进）
每次识别旧模式、经历一次新反应，就是 B 在增长。PERMA 分数的变化、品格优势调用的熟练度、心神合一时刻的频率——这些都是 B 的可测量指标。

### C — 高频（持续性）
觉察不是一次性顿悟，是每天的小练习。Streak（连续天数）就是 C 的量化表达。

## 与觉察助手的关系

觉察本身就是复利行为：
- **每天觉察 = 每天往复利账户存一笔**
- **每次新反应 = 提高收益率**
- **长期坚持 = 时间放大**

不需要额外做什么。觉察的每个环节都在积累复利——只是让用户「看见」这个事实本身，就是强反馈。

### 融入点

| 时机 | 复利视角 |
|------|---------|
| 晚间 R5 | 「今天的新反应，是你往复利账户里存下的又一份本金」 |
| 周洞察 R5 | 把「假设→验证」周期理解为「测试B因子的变化」 |
| 里程碑 | 「连续N天不是数字，是复利曲线开始抬头」 |
| 低谷时 | 「复利的敌人不是收益率低，是中断。今天回来觉察了，C就没断」 |

## 关键原则

- **复利视角是强反馈，不是压力**：不要求每天都有新反应，不把 streak 变成债务。中断了就续上，复利不要求完美，只要求不完全放弃。
- **小 > 大**：每天15分钟觉察 × 1年 > 一次3小时深度觉察 × 然后放弃。觉察助手的设计本身就是小剂量高频。
