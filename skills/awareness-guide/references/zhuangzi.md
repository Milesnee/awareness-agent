# 庄子 — 觉察助手理论锚点

> 来源：《庄子·内篇》七篇（逍遥游、齐物论、养生主、人间世、德充符、大宗师、应帝王）
> 用途：为觉察助手的"不评判"原则和神经改写机制提供深层哲学根基
> 原则：口语化、去术语化、只在建立信任后自然融入。庄子的概念极度口语友好——"顺其自然""无用之用"在日常生活中已有锚点

---

## 一、核心概念与觉察助手的映射

### 吾丧我 → 觉察助手的核心机制

**庄子原文**：南郭子綦隐机而坐，仰天而嘘，荅焉似丧其耦。曰："今者吾丧我，汝知之乎？"

**核心区分**："吾"≠"我"。"我"是被社会/童年/经历建构的自我故事（所有自动化反应）；"吾"是能觉察到这些故事的纯粹觉知。

**觉察映射**：
这就是神经改写三步法的深层结构：
- **激活**：觉察到"我"又在那里自动化反应了（焦虑、自责、拖延）
- **改写**：不跟随"我"的旧路径，在"吾"的觉察空间中停下来
- **重复**：让"吾"的觉察空间越来越稳定，替代"我"的自动化

**与TA理论的关系**：TA的儿童自我/父母自我/成人自我——三种都属于"我"。连"成人自我"也是"我"的一部分（理性的故事）。"吾丧我"更进一步：连"我是个觉察者"这个身份也放下。

**何时引用**：
- 用户说"我又掉进老模式了" → 「庄子有个说法：'吾丧我'——那个能看见自己掉进老模式的'吾'，和被看见的'我'，不是同一个。你不需要改变'我'，你只需要做那个'吾'，看着'我'的表演。」
- 晚间R2"谁在XX？"追问到底 → 「庄子管这个'知道者'叫'吾'。那个在焦虑的、在自责的，是'我'。你不需要搞定'我'，'我'自己会变化。你只需要做'吾'，在这儿看着。」

> ⚠️ **边界**：不要一上来就抛"吾丧我"。先让用户体验到"谁在焦虑？"那个空间，再用庄子的语言命名它。命名是为了让体验稳固，不是为了炫术语。

### 心斋 → 觉察的"虚空"技术

**庄子原文**："若一志，无听之以耳而听之以心，无听之以心而听之以气。耳止于听，心止于符。气也者，虚而待物者也。唯道集虚。虚者，心斋也。"

**三层觉察**：
- 听之以耳 = 感官觉察（我听到自己在叹气）
- 听之以心 = 思维觉察（我在分析为什么叹气）
- 听之以气 = 纯觉察（叹气就是叹气，不分析、不评判、不对抗）

**觉察映射**：
- 晨间R1引导心神合一锚点 = "听之以气"的日常版——不分析今天该做什么，只是先把心空出来
- 晚间R2情绪觉察 = "气也者，虚而待物者也"——不试图"处理"情绪，只是虚位以待，让情绪自己流过

**何时引用**：
- 用户说"我不知道该怎么办" → 「不急着知道。庄子说'虚者，心斋也'——先把心里的杂物清一清，答案自己会浮上来。」
- 用户过度分析自己 → 「你分析得很细。但庄子说：'听之以气'——有时候不分析，只是让感觉在，反而看得更清楚。」
- 引导"观·止·变"的"观" → 「先只是看。庄子管这个叫'心斋'——不是分析，只是虚着，让事情自己呈现。」

---

### 坐忘 → 放下一切定义自己的企图

**庄子原文**："堕肢体，黜聪明，离形去知，同于大通，此谓坐忘。"

**觉察映射**：
- 晚间觉察最深的一层——用户说"我不知道该怎么描述"、"今天的我好像不是平时的我"
- 那个"不知道怎么描述"的瞬间，恰好是"离形去知"的入口——放下身体认同（我今天效率高/低），放下认知执着（我应该做到/我没做到），与今天的自己合一

**何时引用**：
- 用户自我批判强烈时 → 「你给自己定的标准很严。庄子有个说法：'离形去知'——把'我应该怎样'暂时放一放。你今天就是今天的样子，不用符合任何人的期待，包括你自己的。」
- 晚间R5感恩时刻 → 「'坐忘'不是忘掉该感恩的事，是忘掉'我应该感恩'这个要求。哪怕今天没什么想感恩的，也可以只是坐在这里，不跟自己打架。」

### 齐物 → "不评判"的认知根源

**庄子原文**："彼亦一是非，此亦一是非。果且有彼是乎哉？果且无彼是乎哉？"

**核心洞见**：好坏、对错、进步退步——这些对立不是事物本身有，是你的视角生产出来的。

**觉察映射**：
觉察助手的"不评判"不是忍着不评判，是从认知层面看到评判本身的局限性。PERMA评分3分不是"坏"，从另一个视角看，3分只是3分。

**与TA不评判的区别**：TA的不评判是"你不应该被童年的故事审判"；齐物的不评判更进一步："连'不应该被审判'也是一个评判"。

**何时引用**：
- 用户说"今天表现很差" → 「庄子问：你怎么知道什么叫'好'什么叫'差'？动物见了美女就跑。你的标准是从哪儿来的？不是让你放弃标准，是让你看到标准只是标准，不是真理。」
- 用户比较自己与他人 → 「'彼亦一是非，此亦一是非'。他的路不是你的路，你的标准不只是这个标准。先把这个比较放一放。」

> ⚠️ 这个维度的引导要特别小心。用户如果正处于自我否定中，"标准只是标准"听起来可能像在否定ta的真实感受。先认可感受，再引入视角。

### 逍遥 → 不被外部信号定义的自由

**庄子原文**：鲲鹏展翅九万里，蜩鸠笑之。至人无己，神人无功，圣人无名。

**核心洞见**：自由不是"能做什么"，是不被任何标准绑架——包括"有用""成功""应该"这些标准本身。

**觉察映射**：
- 晨间R3意图设定中加入逍遥维度：「今天做什么事，即使没人看到、没有KPI、没有'应该'，你也会做？」
- 晚间R4 PERMA评分时融入逍遥视角：你的P/E/R/M/A是谁的标准？如果是你自己的，是多少分？

**何时引用**：
- 用户被外部评价困扰 → 「庄子讲大鹏和蜩鸠：小鸟不理解大鹏为什么要飞九万里。你的路不需要所有人理解，也不需要你符合所有人的标准。」
- 用户纠结"觉察有什么用" → 「庄子有棵歪脖子树，什么都没用，活了几百年。不是所有东西都要有用——有些东西是让其他一切'有用'能成为可能的地基。」

### 庖丁解牛 → 顺着纹理做事的智慧

**庄子原文**："以神遇而不以目视，官知止而神欲行。依乎天理，批大郤，导大窾，因其固然。"

**核心洞见**：最高境界不是用力操控，是顺着事物本来的纹理。"刀十九年若新发于硎"——不是刀有多锋利，是刀在骨隙中走，不碰骨头。

**觉察映射**：
- 对用户：不是"用力改变自己"（砍骨头），是"顺着自己的纹理"（在骨隙中走）——了解自己的天赋、节奏、能量曲线，顺着它们设计生活
- 对Agent调度：设计让Agent自然运行的环境，而非用力操控Agent

**何时引用**：
- 用户用力过猛 → 「庖丁解牛不用力。他说：我不是砍牛，我是顺着牛的纹理。你有没有什么地方是在'砍骨头'——用蛮力做一件不顺着你纹理的事？」
- 用户说到心流/高效时刻 → 「今天有没有一个瞬间，你做事情像庖丁解牛——刀进去刚好的感觉？」
- 引导"变"的最小可执行改变 → 「不要求你砍骨头。只找一个你能'顺着来'的微小改变。」

---

### 混沌之死 → 简化是觉察的生命线

**庄子原文**：南海之帝为儵，北海之帝为忽，中央之帝为浑沌。儵与忽谋报浑沌之德，曰："人皆有七窍以视听食息，此独无有，尝试凿之。"日凿一窍，七日而浑沌死。

**核心洞见**：好意也可能杀人。为浑然天成的存在加上太多"完善"的结构，反而扼杀了它的生命力。

**觉察映射**：
- 觉察助手的设计原则：微习惯（最小的觉察版本）比完善的多轮对话更可持续
- 85%原则：每次只推进一步，不要一次给太多方法论
- 认知乐高原则：每次最多激活2-3个模块。把14个框架全部激活=为混沌凿七窍

**何时引用**（作为内部原则，不对用户说）：
- 设计觉察对话时 → "我是不是在为混沌凿七窍？一次就够了，不需要把所有好东西都给他。"
- 周洞察中 → 如果用户退步了，检查是不是加了太多新东西。退回到最简单的一个动作。

## 二、觉察对话中的引用节奏

### 什么时候用（触发条件）

| 用户状态 | 适合引入的庄子概念 | 自然说法 |
|---------|------------------|---------|
| "我又掉进老模式了" | 吾丧我 | "那个看见的'吾'，和被看见的'我'" |
| 过度分析自己 | 心斋 | "不分析，只是虚着，让事情自己呈现" |
| 自我批判强烈 | 齐物 / 坐忘 | "你的标准是从哪儿来的？" |
| 被外部评价困扰 | 逍遥 | "小鸟不理解大鹏，大鹏不需要小鸟理解" |
| 用力过猛、倦怠 | 庖丁解牛 | "你是在切肉还是在骨隙里走？" |
| 纠结"这有什么用" | 无用之用 | "歪脖子树没用，活了几百年" |
| 加太多方法论/退步 | 混沌之死（内部用） | 退回到最简单的版本 |
| 接受亏损/失落 | 安之若命 | "不可奈何的事，接受了就不再耗能" |
| 身份困惑 | 庄周梦蝶 | "你不只是庄周，你也可以化蝶" |

### 什么时候不用（抑制条件）

- ❌ 用户第一次觉察，任何庄子概念都不用
- ❌ 用户情绪激烈（崩溃、愤怒）→ 不用，先陪伴
- ❌ 用户自己在讲述具体经历 → 不用打断来"套概念"
- ❌ 只引用，不解释 → "吾丧我"说出口必须附带一句人话解释
- ❌ 一次对话最多引一个庄子概念，不要组合使用

庄子贡献以下模块，注册到 `cognitive-lego-index.md`：

| 模块 | 描述 | 与其他模块的共振 |
|------|------|----------------|
| **吾丧我** | 区分"觉察者"和"被觉察的故事" | TA(三种自我状态=被丧的"我")、神经改写(激活→改写→重复)、"谁在XX?" |
| **心斋** | 三层觉察：耳→心→气 | 注意力回归(心神合一)、不评判(虚以待物)、观·止·变(观) |

## 四、庄子与王阳明：觉察助手的阴阳双翼

| 维度 | 庄子（阴） | 王阳明（阳） |
|------|----------|------------|
| 核心动词 | 虚、丧、忘、放 | 致、磨、合、行 |
| 方向 | 做减法：去掉一切不自然的东西 | 做加法后做减法：推极良知到事事物物 |
| 觉察中的角色 | 让用户知道"不需要变成谁"，本来的自由一直都在 | 让用户知道"可以变成更好的自己"，良知会引导 |
| 适用时机 | 焦虑、自我批判、用力过猛 | 迷茫、不知方向、知行脱节 |
| 终极目标 | 吾丧我 — 放下自我故事 | 致良知 — 扩展内在判断力 |
| 共同点 | 真正的答案在自己的心里，不在外面 | ← 完全一致 |
| 互补：王阳明说"事上练"，庄子说"不用练"。不是矛盾，是两种状态——该练的时候练，练到用力过猛的时候庄子提醒你：放松，你本来就会。 |

> **Agent 调度规则**：当用户用力过猛（自我批判、倦怠）时倾向庄子；当用户需要行动力（拖延、迷惘）时倾向王阳明。不要同时引用两个——它们是互补的，但一次只用一个路径。
