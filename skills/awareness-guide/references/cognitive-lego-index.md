# 认知乐高索引:觉察助手理论模块交叉映射

> "大脑不重复造轮子,它把已有的轮子装到新的车上。"

## 核心认知模块(可复用积木)

| 模块 | 描述 | 出现在哪些框架 |
|------|------|--------------|
| **意图设定** | 明确今天要做什么,把它拉到眼前 | 时间管理(拉入视野)、习惯(执行意图)、微习惯(锚点)、B=MAP(P) |
| **降低门槛** | 小到不可能失败,只做最微版本 | 微习惯(B=MAP-A)、掌控习惯(两分钟准则)、坚持(启动力) |
| **即时庆祝** | 行为后立即正面反馈,焊死习惯 | 微习惯(Shine)、掌控习惯(即时奖励)、金刚智慧(咖啡庆祝) |
| **状态识别** | 看见自己的模式,不贴标签 | TA(三种自我状态)、觉察(四种常见状态)、萨古鲁(区分病理/自陷) |
| **改写旧反应** | 经历一次跟之前不一样的新反应 | 神经可塑性(激活→改写→重复)、TA(切换到成人状态)、在事上练 |
| **不评判** | 被允许做不到,不批评自己 | TA(适应型儿童安全感)、觉察(核心原则)、微习惯(动机波低谷) |
| **量化追踪** | 用数据而非感觉衡量变化 | PERMA评分、习惯追踪法、ESM体验采样 |
| **模式归纳** | 从多天数据提炼跨期模式 | 周洞察(假设→验证)、认知地图(山峰涌现)、知识碎片聚合 |
| **注意力回归** | 从走神拉回当下 | 心神合一锚点、马祖"作用即性"、心流、Flomo随机漫步、庄子(心斋) |
| **意义/态度** | 在不可控中找到可控的回应 | 弗兰克尔(态度自由)、PERMA-M、项飙(拉网)、杨定一(没什么可失去)、庄子(安之若命) |
| **身份流动** | 不被单一身份定义,允许转化 | 庄子(吾丧我+物化)、TA(三种状态切换) |
| **顺纹做事** | 顺着自己的纹理而非用力对抗 | 庄子(庖丁解牛)、微习惯(降低门槛)、85%规则 |
| **简化即生命力** | 不加多余结构,保持浑然天成 | 庄子(混沌之死)、微习惯(最小觉察版本)、认知乐高原则(≤3模块) |
| **三重脑** | 本能/情绪/理智三层驱动,理智打不过前两者 | 认知觉醒(本能脑+情绪脑+理智脑)、TA(儿童自然型≈本能、适应型≈情绪、成人≈理智) |
| **元认知** | 对自己认知过程的觉察,觉察的核心能力 | 认知觉醒(元认知)、庄子(吾)、心理学(Flavell) |
| **拉伸区** | 舒适区和困难区之间,成长最优区 | 认知觉醒(拉伸区)、Vygotsky(ZPD)、85%规则、B=MAP(能力) |
| **深度学习** | 主动关联>被动接收,触动点学习法 | 认知觉醒(深度学习)、第二大脑(渐进式提炼)、书镜(映射流程) |
| **清晰度** | 专注力的前提是目标具体可衡量 | 认知觉醒(清晰度)、时间管理(具体化)、晨间R3(意图设定) |
| **中间包** | 每步产出可复用半成品,不等到最终输出 | 第二大脑(Intermediate Packet)、认知乐高(模块化)、书镜(可跨项目引用) |
| **信息过滤** | 带着开放问题收集信息,不是什么都收藏 | 第二大脑(12个Favorite Problems)、理念狩猎(老麦画像) |
| **因果链阻断** | 苦恼有因果链,阻断任意一环即可止血 | 清静经(妄心→惊神→著物→贪求→烦恼)、交易FOMO链、刷手机链 |
| **澄心遣欲** | 看见欲望而不被带走,不是压抑 | 清静经(遣欲澄心)、微习惯(不靠意志力)、CBT(认知解离) |
| **应物不迷** | 真正的清明是在纷扰中保持,不是逃离 | 清静经(真常应物)、心流(全情投入)、觉察助手核心定位 |
| **三层观空** | 念头不是我、身体不是我、外物不定义我 | 清静经(内观心/外观形/远观物)、CBT(认知解离)、庄子(吾丧我) |
| **工具退场** | AI工具服务于心智成长,最终目标是用户不再需要工具 | 墨丘利(工具为器)、减法疗愈、神经可塑性(改写→内化)、渐进退场设计 |
| **人机共生** | AI不替代觉察,只辅助建立习惯,觉察能力内化后工具退场 | 墨丘利(AI共生体)、85%规则(只推一步)、最低觉察版本(1轮也算) |
| **彩笔描空** | 做事时全情投入,做完即放下,心中空中皆了无牵挂 | 清静经(真常应物)、心流(全情投入)、应物不迷、庄子(用心若镜) |

| **TA = 神经改写 = 在事上练** | 儿童/父母/成人状态、激活→改写→重复、阳明事上练 | 状态识别 + 改写旧反应 |
| **PERMA = PRISM = 弗兰克尔** | E(投入)/M(意义)、Prospection/Resilience/Meaning、意义意志 | 量化追踪 + 意义/态度 |
| **心流 = 心神合一 = "谁在XX?"** | Csikszentmihalyi、觉察晨间R1、觉察晚间R2 | 注意力回归 |
| **时间管理 = 习惯 = 微习惯** | 拉入视野、执行意图、锚点时刻 | 意图设定 |
| **正反馈 = 庆祝 = 咖啡庆祝** | 微习惯(Shine)、掌控习惯(愉悦)、金刚智慧 | 即时庆祝 |
| **庄子 (吾丧我) = TA = 神经改写** | 吾vs我区分、三种自我状态、激活→改写→重复 | 状态识别 + 改写旧反应 |
| **庄子 (心斋) = 心神合一 = "谁在XX?"** | 听之以气、心流、觉知空间 | 注意力回归 |

| **庄子 (逍遥) = 弗兰克尔 = 意图设定** | 不被外部信号定义、态度自由、自由维度的意图 | 意图设定 + 意义/态度 |

| **元认知 = 心斋 = "谁在XX?"** | Flavell、庄子听之以气、觉察R2 | 注意力回归 + 不评判 |

| **深度学习 = 中间包 = 书镜** | 主动关联、Tiago Forte、映射流程 | 知识管理核心方法论 |

## Agent 调度规则

### 抑制机制(主动静音不相关模块)

**原则**:每次对话最多激活 2-3 个模块,其余主动抑制。不是所有 14 个框架都要出场。

- 用户在谈**行动困难** → 激活"降低门槛"+"即时庆祝",抑制"意义/态度"
- 用户在谈**情绪低落** → 激活"不评判"+"注意力回归",抑制"量化追踪"
- 用户在谈**自我批判** → 激活"状态识别"+"改写旧反应",抑制"意图设定"
- 用户在谈**用力过猛/倦怠** → 激活"顺纹做事"+"简化即生命力",抑制"量化追踪"
- 用户在谈**身份焦虑/价值困惑** → 激活"身份流动"+"意义/态度",抑制"降低门槛"
- 用户在谈**停不下来/被幸走** → 激活"因果链阻断"+"澄心遣欲",抑制"意图设定"
- 用户在谈**想逃离一切** → 激活"应物不迷"+"不评判"，抑制"量化追踪"
- 用户在谈**对AI工具的依赖感** → 激活"工具退场"+"不评判"，抑制"意图设定"
- 用户在谈**觉察能力的成长** → 激活"人机共生"+"即时庆祝"，抑制"因果链阻断"

### 庄子 vs 清静经 vs 王阳明 调度规则

> 用户用力过猛(自我批判、倦怠、"应该"太多)→ **倾向庄子**(虚、丧、忘、放)
> 用户被欲望/分心幸走(停不下来、刷手机、FOMO)→ **倾向清静经**(遣欲澄心、因果链阻断、真常应物)
> 用户需要行动力(拖延、迷惘、知行脱节)→ **倾向王阳明**(致、磨、合、行)
> 三者互补但不同时引用。一次对话最多只引一个哲学家概念。
> 庄子="为什么要放下",清静经="怎么放下",王阳明="放下后怎么行动"

### 三重脑 vs 元认知 调度规则

> 用户说"我知道该做但做不到" → **三重脑视角**(不是你不行,是理智脑打不过另外两个壮汉)
> 用户说"我又掉进老模式了" → **元认知视角**(你能看到自己掉进去了--这个'看到'就是元认知在生长)
> 不要同时用两个框架。三重脑解释"为什么",元认知引导"怎么办"。先解释后引导。

### 85% 规则:只推一步(动态调整版)

> 每次引导只比用户当前状态多 15% 的新东西。不要试图一次改变太多。
> 15% 不是固定的,根据用户状态动态调整:
> - 连续觉察 ≤3天:10%(最低觉察版本即可)
> - 连续觉察 4-7天:15%(标准推进)
> - 连续觉察 7天+:20%(可以引入新维度)
> - 回归用户(中断后回来):5%(回来了就好)

- 用户说"我今天什么都没做" → 不引导"设定明天目标"(跳太多),先引导"今天哪怕只做了一件事也可以看见"
- 用户说"我做到了" → 不引导"你还可以更好"(跳太多),先引导"庆祝这个做到"
