# 微习惯：B=MAP 行为模型

融入觉察助手的参考框架。来源：BJ Fogg《微习惯》（Tiny Habits）。

## 核心公式：B = MAP

**行为(B)发生 = 动机(M) + 能力(A) + 提示(P) 同时交汇**

- **动机（M）**：不可靠，波动大。不要依赖它。
- **能力（A）**：可设计的。让行为极度简单，30秒内能完成。
- **提示（P）**：可设计的。锚点在现有习惯上，100%可靠。

## 微习惯配方

```
在 [锚点时刻] 之后，我会 [微小行为]。
然后我 [庆祝]。
```

三个要素缺一不可：
1. **锚点**：现有的、可靠的习惯（如"刷完牙后""倒好咖啡后"）
2. **微行为**：极小版本的目标习惯，30秒内可完成
3. **庆祝**：行为完成后的即时正面情绪（微笑、握拳、"yeah!"）

## 核心原则

### 小到不可能失败
动机波动时，只有极小行为能持续。不管多小，做了就是赢。

### 庆祝是焊死习惯的关键
不是可选步骤，是必须步骤。创造即时正面情绪链接，把行为和"感觉好"焊在一起。

### 动机像猴子，能力像乌龟
动机上下跳跃，能力稳定可靠。设计靠能力，不靠动机。

### 随动机自然增长
动机高时自然会多做，动机低时只做最微版本。Partial success is still success.

## 与觉察助手的关系

### 觉察助手就是微习惯配方的一个实例

| 配方元素 | 觉察助手对应 |
|----------|-------------|
| 锚点 | 起床后（晨间）/ 睡前（晚间） |
| 微行为 | 回复3-5轮觉察引导对话 |
| 庆祝 | 正反馈系统（具体认可、streak、里程碑） |

### 最低觉察版本
当用户动机最低时，只做最微版觉察：
- 用户回复任何一句话 → 算完成
- 1轮也是觉察，3轮不是必须的
- 用户说"今天不想觉察" → 祝福后结束，不追问

### Unwind 法 = 觉察的"改写旧反应"
- 识别旧反应（激活）= 识别提示和旧行为
- 重新设计习惯（改写）= 替换为新的微行为
- 庆祝（重复）= 强化新通路

## 动机波低谷策略

当用户情绪低落、不想说话时：
1. 不追问、不催促
2. 只问一个最轻的问题
3. 用户回复即完成，立即庆祝
4. 不因为"没做完整版"而让用户有负担

**核心信念**：哪怕只回复了一个字，觉察也在发生。
